她支持哪些扩展点

右键菜单在 plugin.json 的 menu 里写一项，就会出现在右键菜单里（和「打个招呼」同级）。
气泡说话window.petPlugins.bubble('你好', 4) —— 让她头顶冒一句话，不花 token、不发声。
表情window.petPlugins.expression('爱心眼') —— 切表情（名称见右键「表情」里那些）。
动作window.petPlugins.motion('Idle') —— 播一个动作组。
情绪反应window.petPlugins.gesture('happy') —— 触发一次情绪小反应。
语音写 command.txt 里一行 SAY:台词，她会用她的声音念出来（见文档）。

五分钟写一个插件

目录结构：

pet-shell/plugins/clock/
├─ plugin.json     ← 描述自己
└─ index.js        ← 页面里执行的代码

plugin.json：

{
  "id": "clock",
  "name": "现在几点了",
  "version": "0.1.0",
  "author": "你的名字",
  "description": "点一下，她用气泡报时间",
  "menu": [{ "id": "time", "label": "现在几点了", "icon": "🕒" }],
  "entry": "index.js"
}

index.js：

window.petPlugins.register('clock', {
  action(actionId) {
    if (actionId === 'time') {
      const t = new Date().toLocaleTimeString('zh-CN',
        { hour: '2-digit', minute: '2-digit' });
      window.petPlugins.bubble('现在 ' + t + ' 啦~', 4);
      return true;
    }
    return false;
  }
});

返回值 true 表示已处理；返回 false 会在日志里记一笔，方便排查。
