# 排查手册

## 她听不懂我说话

看 `brain\voice_bridge.log`，按日志分三种情况：

| 日志 | 含义 | 怎么办 |
|---|---|---|
| `听到：'...'` | 识别成功 | 正常 |
| `（x 秒片段电平 0.00xx < 0.00xx，判定噪声丢弃）` | 被判成噪声 | 门限跟随房间底噪；离麦克风近一点、说话大声点 |
| `心跳：麦克风峰值 0.0000` | 麦克风没收到声音 | 换设备（`voice_bridge.py --devices` 看电平） |
| `问大脑失败：…` | 模型接口报错 | 看后面对应条目 |

## 她回话但很慢

* 打开设置看模型名是否正确（错误的模型名会让接口 400/超时）
* `deepseek-flash` 一般 1~4 秒；换更小的模型会更快
* 语音 3 秒内的"任务型"请求会先说一句「好，我去看看」

## 她周围的东西点不了

托盘菜单里「⚠️ 整窗吞鼠标」被打开了。点一下关掉（它也会 60 秒后自动恢复）。
正常情况下只有她身上的像素接收鼠标。

## 她不动 / 卡在某个姿势

页面在重新适配模型时会有短暂静止（< 1 秒）。
如果一直不动：任务管理器结束 `electron.exe`，重新启动。

## 窗口越拖越大 / 缩放漂移

已在 `app/shell/windowState.js` 里用"唯一真相 + 拖动中不采信 resize + ≤8px 抖动忽略"解决。
如果你改了这部分，请跑 `python tests/test_regressions.py`，A1/A2 会守住。

## 半边身子被切

两个原因：
1. 漫游模式下窗口被改小（现在漫游期间禁止改窗口尺寸，看门狗每 1.5 秒钉回全屏）
2. 放大超过画布高度（现在的缩放上限是画布高度的 88%）

跑 `F1/F3/F5` 用例可验证。

## 设置窗口看不见

她是置顶窗口；设置窗口也被置顶到同一层。**如果还是看不见，看托盘菜单是否有多个实例**，
或者 `POST /settings/close` 关掉再打开。

## 同一句话回答很多次

根因是音箱的声音被麦克风又收了一遍（回声环）。已在 `voice_bridge.py` 里三层防护：
说话期间静音麦克风、6 秒内同句去重、低电平幽灵片段丢弃。

## API 返回 400

**模型名必须填接口的模型 ID**：

| 供应商 | 合法模型名 |
|---|---|
| DeepSeek | `deepseek-flash`、`deepseek-v4-pro` |
| Z.AI (GLM) | `glm-4-flash`、`glm-4.6` |
| OpenAI | `gpt-4o-mini`、`gpt-4o` |

界面上显示的名字（如 "DeepSeek V4.1flash"）不能直接填。
